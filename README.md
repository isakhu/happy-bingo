# Happy Bingo

Offline Bingo caller and management software for Windows.

## Current MVP

- 75-number Bingo caller
- No repeated numbers within a game
- Large current-number display
- Called-number board
- Player count and entry-fee setup
- Configurable manager percentage
- Automatic total collection, manager fee, and prize-pool calculation
- Offline-first desktop architecture

## Planned

- Printable 5x5 Bingo card generator
- Bingo verification workflow
- Amharic and English offline voice announcements
- Game history and reports
- SQLite persistence
- Receipt/print support
- Windows installer and commercial licensing
