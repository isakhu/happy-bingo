# Happy Bingo Offline Licensing

Licensing is designed for offline customers. The customer does not need internet after activation. The activation key is generated for the displayed machine ID by the software owner.

## Password
First launch uses the default setup password `20260817`, then requires the customer to create and confirm a new launch password. The Cartella Builder does not have a second password after launch authentication.

## Important
The license foundation is intentionally separate from the working voice system. Do not modify the audio bridge or voice assets while integrating licensing.
